# Inkbar

Мини-утилита для macOS, которая прячет чёлку MacBook: верхняя полоса экрана постоянно чёрная, и камера сливается с строкой меню.

Работает на macOS 14 и новее, включая macOS 27. Чёрная полоса рисуется на обоях, поэтому строка меню остаётся настоящей системной.

## Как пользоваться

1. Соберите приложение в Xcode или командой:

   ```bash
   xcodebuild -scheme Inkbar -configuration Release -derivedDataPath build
   ```

2. Скопируйте `Inkbar.app` в папку **Программы** (готовый билд лежит в `build/Build/Products/Release/Inkbar.app`).
3. Запустите. В строке меню появится иконка с «чёлкой».
4. Включите **Открывать при входе в систему**, если нужно.

По умолчанию чёрная полоса только на встроенном дисплее с чёлкой. Внешние мониторы можно покрыть отдельно из меню.

В полноэкранных приложениях полоса скрывается, чтобы не перекрывать видео.

## Если полоса не чёрная

В **Системных настройках → Строка меню** выключите «Показывать фон строки меню», если он включён. Фон Liquid Glass тогда снова прозрачный, и сквозь него видна чёрная полоса Inkbar.
